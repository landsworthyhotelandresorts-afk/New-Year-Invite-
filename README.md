# Green Court Resort Pench — Ring in 2027

Landing page for the New Year 2027 celebration at Green Court Resort, Pench.

## Files

- `index.html` — complete landing page. This is the only file required for the page itself.
- No separate `style.css` is required because the page's custom CSS is embedded in `index.html`.
- The page uses Tailwind CSS and Google Fonts through their public CDNs.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Click **Save**.
7. GitHub will provide the live Pages URL.

Keep the repository's `index.html` in the root folder for the landing page to load correctly.
